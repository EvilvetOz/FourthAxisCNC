# Uploading this package to GitHub

For an empty repository using the GitHub web interface:

1. Open the repository.
2. Click **uploading an existing file** in the Quick setup panel.
3. Open the extracted `FourthAxisCNC_v2.23` folder on your PC.
4. Drag the repository contents into the upload area. GitHub's web uploader preserves the files you upload but may be awkward with nested folders; if it refuses the folders, use GitHub Desktop instead.
5. Use a commit message such as `Initial v2.23 release`.
6. Commit the files while the repository is still private.
7. Check that `README.md` renders as the repository front page and that `src/uccnc_4th_axis_generator_V2.23.py` opens normally.
8. Check that the included images render correctly in the README.
9. Only make the repository public after checking that no personal information is present.

## GitHub Desktop alternative

If the browser upload is awkward with the folder structure, choose **Set up in GitHub Desktop** from the repository page, clone the empty repository, copy all files from this package into the cloned folder, then commit and push.
